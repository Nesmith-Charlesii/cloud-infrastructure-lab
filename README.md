# Cloud Infrastructure Lab

A production-inspired infrastructure lab built to develop hands-on experience with cloud networking, Linux, Terraform, Terragrunt, Kubernetes, monitoring, and AWS.

## Project Goal

Build a miniature enterprise cloud environment from the ground up while documenting the architecture, configuration, and troubleshooting process.

## Planned Technologies

* AWS
* Terraform
* Terragrunt
* Linux
* Docker
* Kubernetes
* DNS and networking
* Monitoring and observability

## Status

Project initialization in progress.
